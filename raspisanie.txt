# Как заполнять:
#   - каждый день — отдельный блок, между блоками пустая строка;
#   - первая строка блока — дата: «8 октября 2026»;
#   - вторая строка — праздник дня (можно не писать). Перед большим праздником поставьте «!»;
#   - следующие строки — службы: время и название, например «17:00 Всенощное бдение».
#   Дни без служб и без праздника можно не писать.
#   Строки, которые начинаются с «#», — пояснения, сайт их не показывает.
#
# Как добавить новый месяц: допишите его в конец файла по тому же образцу.
